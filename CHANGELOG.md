# Changelog

All notable changes to TerraVerse are documented here.
Versions follow [Semantic Versioning](https://semver.org): MAJOR.MINOR.PATCH.

## [1.0.0] — 2026-11-27

### Added
- 14 animated realms: Animals, Birds, Fishes & Ocean Life, Insects, Plants & Flowers, Trees & Forests, Medicinal Plants, Microbes & Bacteria, Mountains & Volcanoes, Stars, Galaxies, Moons & Satellites, Languages & Scripts, Extinct Life.
- 135 in-depth entries with timelines, species, life & behaviour, DNA & genome, extinction causes and alphabets.
- 416+ featured topics and live search across Wikipedia, with full articles and photo galleries on every page.
- Themed particle worlds, parallax landscapes and animated charts (mass extinctions, mountain heights, cosmic distances, script family tree).
- Encrypted SQLite database (AES-256-GCM) with the key held only as a GitHub secret.
- Encrypted backup of the source content (vault/).
- One-file GitHub Actions workflow: unpacks uploads, tags versions, publishes Releases and deploys to GitHub Pages.
